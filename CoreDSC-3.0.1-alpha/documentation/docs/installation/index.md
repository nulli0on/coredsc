# Installation

Use this sequence for a new server:

1. Install the CoreDSC JAR.
2. Start Paper once so the default files are created.
3. Stop the server.
4. Configure the bot token and guild ID.
5. Configure one feature, usually chat sync.
6. Start Paper and run the diagnostics.
7. Enable additional modules one at a time.

Do not copy a full configuration from another server without reviewing IDs, role mappings and command permissions.

## Before you begin

- Back up the server.
- Confirm Java 21 is active.
- Create a dedicated Discord bot application.
- Decide which Discord server and channels CoreDSC will use.
- Keep remote console, Python, workflows and community modules disabled until the basic bridge is stable.

Continue with [Initial setup](./initial-setup.mdx).
