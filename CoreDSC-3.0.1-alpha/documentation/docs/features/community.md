# Tickets, reports and applications

These modules store user-generated content. Back up the database and restrict staff permissions.

## Tickets

Creates a Discord thread connected to a linked player. Limits include cooldown, open tickets per user, global capacity and message length. Staff roles can claim, prioritize, reply to and close tickets.

## Reports

Creates structured reports for a target Minecraft player. The module can include bounded chat context and expose a configurable staff inventory. Review privacy obligations before storing chat history.

## Cases and appeals

Stores moderation cases and allows linked users to create appeals. Staff roles control case viewing and closure.

## Applications

Collects configured questions and opens a Discord thread for staff review. Acceptance actions may whitelist a player, assign a LuckPerms group, assign a Discord role or run explicitly allowed console commands.

Keep console actions disabled until the exact allowlist is reviewed.
